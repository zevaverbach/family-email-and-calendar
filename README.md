# Mail Server Infrastructure

This project sets up a mail server infrastructure using Pulumi, combining Hetzner Cloud for hosting, AWS SES for email delivery, and Cloudflare for DNS management. The setup includes a complete mail server solution with DKIM, SPF, and DMARC configuration.

## Prerequisites

- Pulumi CLI installed
- AWS CLI configured with appropriate credentials
- Hetzner Cloud account and API token
- Cloudflare account and API token
- SSH key pair (named "mail-server-key" in Hetzner Cloud)

## Configuration

Before deploying, you need to set up the following Pulumi configuration values:

```bash
# Required configuration values
pulumi config set domain example.com
pulumi config set admin_email admin@example.com
pulumi config set cloudflare_zone_id your_cloudflare_zone_id

# Hetzner configuration
pulumi config set --secret hcloud:token YOUR_HETZNER_API_TOKEN

# Cloudflare configuration
pulumi config set --secret cloudflare:apiToken YOUR_CLOUDFLARE_API_TOKEN
```

Also make sure you've got AWS credentials and config in `~/.aws`.

## Environment Variables

The following environment variables are automatically configured in the mail server:

```env
DOMAIN=<your-domain>
HOSTNAME=mail.<your-domain>
SECRET_KEY=<auto-generated>
SUBNET=192.168.203.0/24
ENABLE_SIGNUP=False
ADMIN=<your-admin-email>
MESSAGE_SIZE_LIMIT=50000000
POSTMASTER=admin
RELAYHOST=email-smtp.us-east-1.amazonaws.com:587
RELAYUSER=<aws-ses-smtp-user>
RELAYPASSWORD=<aws-ses-smtp-password>
RELAYTLS=yes
```

## Deployment

To deploy the infrastructure:

```bash
pulumi up
```

## Important Outputs

After deployment, Pulumi will output:
- Server IP address
- SMTP credentials for AWS SES
- DKIM DNS records

## DNS Records

The following DNS records are automatically created in Cloudflare:
- A record for mail subdomain
- MX record
- SPF record
- DMARC record
- DKIM records
- PTR hint record

## Security Notes

- All DNS records are created with `proxied: false` to ensure direct mail server connectivity
- SMTP credentials are managed securely through AWS IAM
- The mail server is configured with restricted signup

## Maintenance

The mail server data is stored in `/data/mailu/` on the Hetzner instance. Regular backups of this directory are recommended.
